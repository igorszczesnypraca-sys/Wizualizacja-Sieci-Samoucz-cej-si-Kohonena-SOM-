# Wizualizacja Sieci Samouczącej się Kohonena (SOM)
Implementacja od podstaw algorytmu sztucznych sieci neuronowych (BMU, odległość euklidesowa, funkcja Gaussa) wraz z wielowątkowym interfejsem graficznym pozwalającym na obserwowanie dynamicznego morfingu siatki w czasie rzeczywistym.  (Technologie: Java, Swing).
